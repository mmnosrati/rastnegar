## 📖 معرفی پروژه

**راست‌نگار** یک استودیو و ریدر وب مدرن و اختصاصی برای زبان فارسی و خطوط راست‌به‌چپ (RTL) است که با هدف حل اساسی مشکلات چیدمان دوطرفه (**BiDi**) در متون نشانه‌گذاری مارک‌داون (Markdown) طراحی شده است.

احتمالاً بارها تجربه کرده‌اید که هنگام کپی کردن خروجی مدل‌های هوش مصنوعی (مانند **ChatGPT**، **Claude**، **Gemini** و...) که همگی در قالب Markdown ارائه می‌شوند، ترکیب کلمات انگلیسی، کدها، پرانتزها و اعداد درون متن فارسی کاملاً به‌هم می‌ریزد و ساختار جملات معکوس می‌شود. **راست‌نگار** با الهام از اصول و هسته پروژه ارزشمند [dariubs/rtlmd](https://github.com/dariubs/rtlmd) و ترکیب آن با تایپوگرافی چشم‌نواز فارسی، محیطی پایدار و بدون نقص برای نوشتن و خواندن این متون فراهم کرده است.

## ✨ ویژگی‌های برجسته

### ۱. حل اساسی چالش‌های BiDi و چیدمان فارسی
- **رندرینگ کاملاً استاندارد:** بر خلاف ویرایشگرهای عادی، در راست‌نگار کدهای انگلیسی، عبارات درون‌خطی و پرانتزها با برچسب ایزوله‌ساز `<bdi>` محافظت می‌شوند تا ترتیب خوانش جملات دستخوش تغییر نشود.
- **ایزوله‌سازی قطعه‌کدها:** کلیه بلوک‌های کد (`pre` و `code`) همواره به صورت استاندارد چپ‌به‌راست (`dir="ltr"`) همراه با هایلایت نحوی Prism.js و دکمه کپی فوری نمایش داده می‌شوند.
- **سازگاری با متون طولانی و فنی:** بررسی‌شده با اسناد سنگین فنی چندزبانه (شامل جدول، چک‌لیست، کدهای bash، yaml و powershell).

### ۲. خروجی‌های خودکفا و مستقل
- 📄 **دانلود مستقیم فایل PDF (قطع A4):** بدون باز شدن پنجره پرینت مرورگر، سند شما با یک کلیک مستقیماً به صورت فایل PDF استاندارد با تایپوگرافی کامل دانلود می‌شود.
- 🌐 **خروجی HTML مستقل و پایدار:** صفحه وب کامل با استایل‌های اینلاین و ساختار راست‌چین توکار؛ به طوری که حتی با جابجایی فایل یا استفاده در محیط آفلاین، شکل ظاهری و فونت‌ها به هیچ وجه به‌هم نمی‌ریزد.
- 📋 **کپی متن با فرمت (Rich Text):** جهت انتقال مستقیم به نرم‌افزارهای ورد (Microsoft Word)، تلگرام، ایمیل و سایر ویرایشگرها با حفظ کامل ساختار.
- 💾 **دانلود فایل مارک‌داون (.md):** ذخیره آنی متن سورس.

### ۳. طراحی پرمیوم و دور از کلیشه‌ها
- **۵ پالت رنگی با کنتراست بالا و استاندارد WCAG:**
  1. **کاغذ و مرکب (Ivory & Ink):** حس نوستالژیک کاغذ پوستی و متون ادیتوریال.
  2. **آبنوس و کهربا (Obsidian Dark):** تم تاریک عمیق با رنگ برنز گرم.
  3. **سرو و زیتون (Nordic Sage):** ترکیب آرامش‌بخش سبز جنگلی و کتان.
  4. **زعفران و لاجورد (Persian Lapis):** اصالت رنگ‌های سنتی ایرانی.
  5. **مونوکروم سوییسی (Swiss Minimalist):** دیزاین مدرن و مینیمال.
- **سه حالت نمایش متنوع:**
  - *نمای دو پنجره‌ای (Split View):* ویرایشگر و پیش‌نمایش زنده در کنار هم.
  - *حالت خوانش (Reader Mode):* محیطی خلوت، کتاب‌گونه و متمرکز برای مطالعه.
  - *حالت تحریریه (Editor Only):* تمرکز کامل بر روی نوشتن.
- **نوار ابزار تایپوگرافی فارسی:** درج سریع نیم‌فاصله‌های استاندارد (`\u200c`)، نقل‌قول‌ها، عناوین و جداول.
- **فهرست خودکار سرفصل‌ها (TOC):** استخراج هوشمند عناوین با امکان اسکرول روان به بخش‌های مختلف.

## 🛠️ ساختار فنی پروژه

پروژه به صورت یک اپلیکیشن استاتیک سریع با قابلیت اجرا بر بستر ابری **Cloudflare Workers (Pages / Static Assets)** ساخته شده است:

```
├── public/
│   ├── css/
│   │   ├── app.css              # استایل‌های اصلی، سیستم متغیرهای تم و ریسپانسیو
│   │   └── prism-rastnegar.css  # هایلایتینگ کدهای برنامه‌نویسی
│   ├── js/
│   │   ├── app.js               # منطق اصلی رابط کاربری، استیت‌ها و ذخیره‌سازی
│   │   ├── bidi-engine.js       # موتور پردازش Markdown و تصحیح BiDi (مبتنی بر rtlmd)
│   │   └── presets.js           # اسناد پیش‌فرض نمونه و راهنما
│   ├── vendor/                  # کتابخانه‌های marked, prism, dompurify
│   └── index.html               # اسکلت اصلی برنامه
├── wrangler.jsonc               # پیکربندی دیپلوی Cloudflare Workers
└── README.md
```

## 🚀 نحوه اجرا به صورت محلی (Local Development)

برای اجرای راست‌نگار روی سیستم خود، نیازی به نصب بیلد تولزهای پیچیده ندارید:

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/mmnosrati/rastnegar.git
cd rastnegar

# اجرای یک سرور محلی ساده (با پایتون یا Node.js)
# روش اول (پایتون):
python -m http.server 3000 --directory public

# روش دوم (Node.js):
npx serve public
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.

## ☁️ نحوه دیپلوی روی Cloudflare Workers

این پروژه با ابزار `wrangler` پیکربندی شده است:

```bash

npx wrangler login

# دیپلوی پروژه
npx wrangler deploy
```
