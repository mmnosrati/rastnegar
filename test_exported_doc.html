۰.۱ C2 چیست؟

C2 مخفف Command and Control است. تصور کنید شما یک فرمانده هستید و می‌خواهید به یک سرباز در نقطه‌ای دور دستور بدهید. C2 همان سیستم ارتباطی بین شما (فرمانده) و سرباز (کامپیوتر قربانی) است.

اجزای C2:

  • سرور C2: کامپیوتر شما (یا VPS) که دستورات را می‌فرستد
  • Agent / Implant: برنامه‌ای که روی کامپیوتر قربانی اجرا می‌شود و منتظر دستور شماست
  • Listener: پورتی روی سرور شما که منتظر اتصال Agent است
